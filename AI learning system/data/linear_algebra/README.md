# 线性代数资料集

原创学习资料，用于 AI 学习辅助系统 Level 2 的 Markdown 分析、知识点提取、资料来源引用、跨章节检索与证据不足处理。

包含 **20 份课程资料、5 份题目文件（40 道模拟题）、5 份参考解析**，正文合计 **29,286 个字符**（包含 Markdown 与数学记号，非模型 token 数）。题目不是实际历年真题；不标注虚构年份或学校。

## 目录与导入边界

- `resources/`：课程正文，作为知识分析与问答的原始资料。
- `problems/`：模拟题库，包含稳定题号、题型和知识点提示 ID。
- `solutions/`：参考答案，独立保存用于评估或反馈，默认不导入课程问答索引。
- `evaluation_queries.json`：12 个检索与证据充分性检查问题，不作为课程知识导入。
- `manifest.json`：文档标识、字符统计与 SHA-256；资料修改后需重新生成对应记录。

Markdown 使用 UTF-8，每份有 `document_id`、`kind`、`subject` 元数据；课程文件还有 `level`。
标题与小节可作为切分边界。抽取时保留原文、标题路径和行号，后续知识图只作组织，原文才是回答证据。
题目中的知识点 ID 为人工提示，不是当前 Level 1 网络的强制 ID 映射；正式入库前应做知识点规范化。

当前 Level 1 CLI 仍读取分析结果 JSON；这批 Markdown 供后续 Level 2 使用，尚未自动接入现有网络。

## 检索评估

问题覆盖单章节、跨章节、同义词、错误前提以及缺失算法细节。`expected_resource_files` 是人工建议证据，不是唯一标准；检索命中并不自动说明回答充分。
对 Householder、随机化 SVD 等问题，资料有概览但没有完整算法，应说明可支持的部分与缺失范围。

易错命题文件含明确否定的错误句子；提取 Agent 必须保留否定与条件，不能把错误命题抽成正向事实。
覆盖范围是本科核心与部分拓展；缺失 Jordan 完整算法、张量分解和稀疏求解器等内容，便于测试资料不足场景。
