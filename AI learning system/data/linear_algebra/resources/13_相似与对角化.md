# 相似矩阵与对角化

## 1. 相似的定义与不变量
若存在可逆 P，使 B=P^{-1}AP，则 A、B 相似。相似矩阵有相同特征多项式、特征值及代数重数、迹、行列式和秩。

反过来，这些不变量相同不保证相似。例如 I_2 与 [[1,1],[0,1]] 有相同特征值、迹、行列式和秩，但二者不相似。

## 2. 对角化条件
n 阶矩阵 A 可对角化，指存在可逆 P，使 P^{-1}AP=D 为对角阵。等价条件是 A 有 n 个线性无关特征向量。

把特征向量按列放入 P，对应特征值按同样顺序放入 D，则 AP=PD。顺序不一致会使等式失效。

在特征多项式于所讨论数域完全分解的前提下，可对角化等价于每个特征值的几何重数等于代数重数。讨论实对角化时尤其要注意实特征值是否齐全。

## 3. 足够条件与非必要条件
具有 n 个互异特征值的 n 阶矩阵可对角化。但“特征值互异”不是必要条件，I_n 虽只有一个特征值却已经是对角阵。

重复特征值也不必导致不可对角化。真正障碍是独立特征向量数量不足。矩阵 [[1,1],[0,1]] 正是这种情况。

## 4. 对角化例题
A=[[2,1],[0,3]]，取 P=[[1,1],[0,1]]，D=diag(2,3)。则 AP=PD，从而 P^{-1}AP=D。

对非负整数 k，A^k=PD^kP^{-1}，算得 A^k=[[2^k,3^k−2^k],[0,3^k]]。k=0 时得到 I，k=1 时恢复 A，是两个方便的检查点。

## 5. 递推的应用
若状态 x_{k+1}=Ax_k，则 x_k=A^k x_0。可对角化时，在特征基下各坐标独立按 λ_i^k 演化。

并非所有矩阵都可对角化，不能在未验证条件时直接使用特征基公式。不能把每个特征值的幂直接摆成对角阵而省略 P。

## 6. 与合同的区别
相似变换为 P^{-1}AP，描述线性算子换基；合同变换为 P^TAP，描述实二次型换坐标。一般可逆 P 下两种变换不同。

当 P 是正交矩阵时 P^{-1}=P^T，两式形式重合。这是实对称矩阵用正交对角化处理二次型的原因。
