# 参数矩阵与分类讨论专题

## 1. 为什么分类
矩阵含参数时，秩、可逆性、方程组解的情况都可能在特殊参数值处改变。消元中的除法只在分母非零时合法，所以每个候选主元可能为零的情形都需要检查。

方阵可先用行列式找出可能降秩的位置。非零处必满秩，零点处则继续消元或检查低阶子式；行列式为零只能说明不满秩，不能直接确定具体秩。

## 2. 典型矩阵的秩
A(t)=[[1,1,1],[1,t,1],[1,1,t]]。第二、三行减第一行后得到

```text
[1  1    1]
[0 t-1   0]
[0  0   t-1]
```

所以 det(A)=(t−1)²。t≠1 时秩为 3；t=1 时全为 1，秩为 1，而不是 2。一个参数零点可以造成不止一级的秩下降。

## 3. 同一系数矩阵的相容性
考虑上面的 A(t)x=b。

t≠1 时 A 可逆，对任意 b 唯一可解。
t=1 时三个方程左侧都是 x1+x2+x3，因此要求 b1=b2=b3。若相等，有两个自由变量；若不相等，无解。

比如 b=(1,1,1)^T 在 t=1 有无穷多解；b=(1,0,0)^T 在 t=1 无解。这说明同样的奇异系数矩阵可以因右端项不同而有不同结论。

## 4. 线性相关性的参数
v1=(1,1)^T，v2=(1,t)^T。把二者作列组成 [[1,1],[1,t]]，行列式为 t−1。

t≠1 时无关；t=1 时相同，所以相关。参数代入后的向量长度非零，也不保证整体无关。

## 5. 正定性的参数
A(t)=[[1,t],[t,1]] 对称。顺序主子式为 1、1−t²。正定范围为 −1<t<1。

t=±1 时特征值为 0、2，半正定；|t|>1 时特征值 1+t、1−t 一正一负，不定。所有 t 的对角元素都为正，但正定范围仍受交叉项影响。

## 6. 解题步骤与记录
先说明对象尺寸和目标，再找出影响主元、行列式或主子式符号的参数点；对各区间或特殊点分别计算；最终检查是否覆盖所有参数且各条件互不冲突。

问答回答参数题时应展示分类依据，而非只给出某个“通常情形”。当前语料没有一般多参数符号消元算法，只包含具体题型示范。
