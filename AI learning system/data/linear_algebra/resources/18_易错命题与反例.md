# 易错命题、条件遗漏与反例

## 1. 运算反例
“AB=BA”：一般错误，参见矩阵运算章的两个剪切矩阵。
“AB=0 推出 A=0 或 B=0”：错误，两个互补坐标投影均非零而乘积为零。
“det(A+B)=det(A)+det(B)”：错误，取 A=B=I_2 得到 4≠2。
“(AB)^T=A^TB^T”：顺序错误，正确为 B^TA^T。

## 2. 秩与方程组反例
“方程个数大于未知数必无解”：错误，冗余方程可以相容。
“方程个数少于未知数必有无穷多解”：非齐次系统可能无解；有解后才谈自由参数。
“行列式为零说明 Ax=b 无解”：错误，A=0、b=0 有无穷多解，b≠0 则无解。
“所有元素非零说明满秩”：错误，全 1 矩阵秩为 1。

## 3. 向量组反例
“两两无关说明整体无关”：错误，(1,0)、(0,1)、(1,1) 两两不成比例却整体相关。
“零向量也能作为特征向量”：错误，定义要求非零。
“向量空间的基唯一”：错误，R^2 标准基与 {(1,1),(1,−1)} 都是基。
“两个子空间并集仍是子空间”：一般错误，两条不同过原点直线的并集不对加法封闭。

## 4. 谱与对角化反例
“可逆就能对角化”：错误，[[1,1],[0,1]] 可逆但只有一个独立特征方向。
“有重复特征值就不能对角化”：错误，I_n 已为对角阵。
“相同特征值说明相似”：错误，I_2 与 [[1,1],[0,1]]。
“实矩阵的特征值全为实数”：错误，平面 90 度旋转矩阵有 ±i。

## 5. 正定判定反例
“对角元素正就正定”：错误，[[1,2],[2,1]] 特征值为 3、−1，不定。
“行列式正就正定”：错误，−I_2 行列式为 1，却负定。
“顺序主子式非负就半正定”：错误，diag(0,−1) 的顺序主子式为 0、0，但不是半正定。

正定的顺序主子式判据只适用于实对称矩阵；半正定应检查全部主子式或特征值。

## 6. 检索与回答训练用途
当用户提出以上错误命题，回答应明确纠正并给出反例，不能顺着前提证明。若用户漏掉方阵、满列秩、不同特征值等条件，应先指出条件再下结论。

此文中的错误命题均被明确标为错误，自动知识抽取时必须保留否定信息，不能把引号内的错误句子直接抽成正向事实。
