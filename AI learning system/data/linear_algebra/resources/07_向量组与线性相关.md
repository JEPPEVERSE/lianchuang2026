# 向量组、线性组合与线性相关

## 1. 线性组合与张成
向量 v 的线性表示是 v=c_1v_1+…+c_kv_k。所有这样的组合组成 span(v_1,…,v_k)，称张成空间。

“由向量组线性表示”“属于该向量组张成的空间”是等价说法。判断 b 是否能由 A 的列表示，就是判断 Ax=b 是否有解。线性表示的系数未必唯一。

## 2. 线性无关的定义
若 c_1v_1+…+c_kv_k=0 只允许所有 c_i=0，则向量组线性无关；若存在不全为零的系数满足等式，则线性相关。

这里的零是零向量。判断相关时必须找到非平凡关系，不能把“取所有系数为零”当成相关的证明。

含零向量的非空向量组一定相关。含两个相同向量的向量组也相关。R^n 中超过 n 个向量必相关，但不超过 n 个未必无关。

## 3. 与矩阵秩的关系
把 k 个向量按列组成 A，则向量组无关当且仅当 r(A)=k；相关当且仅当 r(A)<k。向量组的秩定义为其张成空间的维数。

若向量组无关，任意子组也无关；若某个子组相关，添加向量后仍相关。两个向量组张成相同空间称等价，它们的秩相同，但元素个数可能不同。

## 4. 例题：极大无关组
在 R^3 中，v_1=(1,0,1)^T，v_2=(0,1,1)^T，v_3=(1,1,2)^T。因为 v_3=v_1+v_2，三个向量相关。

v_1、v_2 无关，且能表示整个向量组，因此是一组极大线性无关组，向量组秩为 2。极大无关组不唯一，例如 v_1、v_3 也可作为一组。

极大表示不能在原向量组中再添加向量而保持无关；这里不表示某个向量的长度最大。

## 5. 线性表示是否唯一
若 v_1,…,v_k 无关，则它们张成空间中任意向量的表示系数唯一。若向量组相关，则对任何可表示向量，表示通常可沿一个非零齐次关系改变系数，因而不唯一。

上述例中 (2,3,5)^T=2v_1+3v_2；也可写成 v_1+2v_2+v_3。

## 6. 易错点
两两不成比例不能保证三个及以上向量整体无关。上述 v_1、v_2、v_3 两两不成比例却相关。

不同特征值对应的特征向量线性无关是后续的重要结论，但同一特征值的若干特征向量不一定无关。
