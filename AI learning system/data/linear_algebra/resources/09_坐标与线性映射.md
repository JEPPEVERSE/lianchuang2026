# 坐标、换基与线性映射

## 1. 坐标与基矩阵
设 B=(b_1,…,b_n) 是 R^n 的一组基，P=[b_1 … b_n]。向量 x 满足 x=P[x]_B，所以 [x]_B=P^{-1}x。

这里 x 是标准坐标列向量，[x]_B 是 B 基下的坐标。不要把基向量和坐标向量混为一谈。

若 B'=B C，表示新基向量按旧基作线性组合，则 [x]_B=C[x]_{B'}。换基方向必须由这个等式确定，不能只背“乘过渡矩阵”。

## 2. 坐标例题
取 b_1=(1,1)^T，b_2=(1,−1)^T，x=(4,2)^T。解 x=c_1b_1+c_2b_2，有 c_1+c_2=4、c_1−c_2=2，所以 [x]_B=(3,1)^T。

同一个几何向量在标准基下坐标为 (4,2)，在 B 下为 (3,1)，向量本身没有改变。

## 3. 线性映射及矩阵表示
T:V→W 线性意味着 T(αu+βv)=αT(u)+βT(v)。给定定义域基与值域基后，T 的矩阵各列是定义域基向量像的值域坐标。

T(0)=0 是必要条件，但单凭这一点不能证明线性。例如 T(x)=x² 满足 T(0)=0，却不满足加法性。

核 ker(T)={v:T(v)=0}，像 im(T)={T(v):v∈V}。核与像都是子空间。有限维时 dim ker(T)+dim im(T)=dim V。

## 4. 单射与满射
T 单射当且仅当 ker(T)={0}；满射当且仅当 im(T)=W。矩阵语言中，满列秩对应单射，满行秩对应满射。

定义域与值域维数相同且有限时，单射、满射和可逆等价；维数不同时不能把单射和满射混为一谈。

## 5. 同一映射的换基与相似
若线性算子在标准基下矩阵为 A，基矩阵为 P，则新基下矩阵 A_B=P^{-1}AP。两个这样的矩阵称相似，表示同一个算子在不同基下的形式。

如果定义域与值域使用不同基，一般变换为 Q^{-1}AP，不一定是相似变换。相似要求同一空间中的同一基变换作用于两侧。

## 6. 例题与后续联系
T(x,y)=(x+y,y)，标准矩阵 A=[[1,1],[0,1]]，核为零，像为 R^2，所以可逆。

特征向量构成一组基时，新基下算子矩阵成为对角阵。这是对角化的实质。后面的二次型换坐标使用 P^TAP，是合同变换，与这里的 P^{-1}AP 不同。
