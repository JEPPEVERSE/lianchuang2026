# 奇异值分解、低秩近似与伪逆概览

## 1. SVD 的形式
任意实矩阵 A∈R^{m×n} 都存在奇异值分解 A=UΣV^T，U、V 分别为 m 阶和 n 阶正交矩阵，Σ 为 m×n 的矩形对角矩阵，对角元素非负。

奇异值通常按 σ_1≥σ_2≥…≥0 排列。与相似对角化不同，SVD 适用于非方阵以及不可对角化的方阵，左右使用不同正交基。

## 2. 与 A^T A 的关系
σ_i 是 A^T A 特征值的非负平方根；正奇异值数目等于 r(A)。右奇异向量来自 A^T A 的标准正交特征向量。

对 σ_i>0，可定义 u_i=Av_i/σ_i。零奇异值不能用这个除法构造对应向量，需补充正交基。

奇异值总非负，特征值可能负或复，两者不能混同。对实对称矩阵，奇异值是特征值的绝对值。

## 3. 简单例题
A=diag(3,−2) 的特征值为 3、−2，奇异值为 3、2。可取 U=diag(1,−1)，Σ=diag(3,2)，V=I。

若 A=[[3,0],[0,0],[0,0]]，则秩为 1，唯一正奇异值为 3，列空间为 span((1,0,0)^T)，零空间为 span((0,1)^T)。

## 4. 低秩近似
分解可写为 A=Σ_i σ_i u_i v_i^T。截断到前 k 个正奇异值，得到 A_k。

Eckart—Young 定理说明该截断在 Frobenius 范数下给出最优秩不超过 k 的近似，误差平方为 Σ_{i>k}σ_i²；谱范数误差为 σ_{k+1}。

本章只陈述定理，不展开证明，不讨论特定图像压缩或推荐系统算法。

## 5. Moore—Penrose 伪逆
将正奇异值替换为倒数，零保持为零，并转置矩形对角形状，得到 Σ^+。定义 A^+=VΣ^+U^T。

A^+b 是最小二乘解中欧氏范数最小的一个。若 A 满列秩，则 A^+=(A^T A)^{-1}A^T；若 A 可逆，则 A^+=A^{-1}。

矩形或奇异矩阵的伪逆不应当作普通双侧逆，通常 AA^+ 与 A^+A 是投影矩阵。

## 6. 条件数的限定
可逆方阵的二范数条件数为 κ_2(A)=σ_max/σ_min。条件数大表示相对误差可能被显著放大。奇异矩阵没有普通逆，其普通二范数条件数视为无穷大。

本章未提供数值 SVD 的具体迭代实现，也未涉及随机化 SVD；问答时不能假设资料已覆盖这些算法细节。
