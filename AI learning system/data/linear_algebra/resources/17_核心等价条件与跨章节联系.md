# 核心等价条件与跨章节联系

## 1. 方阵可逆的完整链条
对 n 阶实方阵 A，可逆 ⇔ det(A)≠0 ⇔ r(A)=n ⇔ 列向量无关 ⇔ ker(A)={0} ⇔ 对任意 b∈R^n，Ax=b 唯一可解 ⇔ 0 不是特征值。

“对任意 b”是全称条件，不能用某一个右端项的情况替代。对某个 b 有唯一解已经能说明方阵满列秩，但“对某个 b 有解”不能说明可逆。

逆矩阵、行列式、秩、零空间和特征值章节给出这条链的不同侧面。跨章节问答应把必要条件与结论一起引用。

## 2. 矩形矩阵的单射与满射
A 为 m×n：满列秩 ⇔ Ax=0 仅有零解 ⇔ x→Ax 单射 ⇔ A^T A 正定；满行秩 ⇔ C(A)=R^m ⇔ 对任意 b 都可解 ⇔ x→Ax 满射。

若 m>n，可以单射却不满射；若 m<n，可以满射却不单射。维度关系本身只是可能性限制，具体是否单射或满射还要看秩。

## 3. 最小二乘为什么需要正交与正定
最小二乘使 b−Ax 与所有列向量正交，得到正规方程。若满列秩，A^T A 正定并可逆，所以系数唯一。

不满列秩时，投影仍唯一，但可能有多个 x 映到同一个投影。伪逆选出其中范数最小的系数。这条联系横跨秩、零空间、正交投影、正定性和 SVD。

## 4. 可逆与可对角化独立
[[1,1],[0,1]] 可逆但不可对角化；diag(0,1) 可对角化但不可逆。两者分别关心零特征值和独立特征向量数量，不是同一个条件。

对角化能简化幂运算，但解方程并不要求矩阵可对角化。实对称矩阵一定正交对角化，却不一定可逆，例如零矩阵。

## 5. 相似、合同、等价
相似 B=P^{-1}AP：同一算子换基，保持特征值。
合同 B=P^TAP：二次型换变量，实对称情况下保持惯性。
矩阵等价 B=PAQ：P、Q 可逆，保持秩，允许不同的左右变换。

三者都有不同的业务含义，不能因为都有“左右乘可逆矩阵”就当成一种关系。

## 6. 正交性连接的四个对象
列空间与左零空间互为正交补，行空间与零空间互为正交补。对称矩阵的不同特征空间正交；投影残差与被投影空间正交。

这四种正交命题都成立，但向量所属空间和条件不同。检索到“正交”一词不够，需要识别具体对象。

## 7. 有边界的知识范围
本资料集覆盖本科线性代数核心及 SVD 概览，不包含 Jordan 标准形的完整构造、不包含张量分解、不包含稀疏求解器和随机化 SVD 实现。对这些算法细节的问答应说明资料不足，不能靠相近主题填补。
