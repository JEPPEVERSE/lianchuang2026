# 实对称矩阵与正交对角化

## 1. 谱定理
实对称矩阵 A=A^T 的所有特征值都为实数，并存在正交矩阵 Q，使 Q^T A Q=Λ 为实对角阵。也就是 A=QΛQ^T。

列向量 q_i 构成 R^n 的标准正交特征基。重复特征值允许在对应特征空间内部选取任意标准正交基。

普通实矩阵未必能对角化，也未必具有实特征值；谱定理不能不加条件地推广到所有矩阵。

## 2. 不同特征值的正交性
若 Au=λu、Av=μv 且 λ≠μ，对称性给出 u^TAv=(Au)^Tv，故 μu^Tv=λu^Tv，得到 u^Tv=0。

同一特征值下的任意两个特征向量未必正交；可以在这个特征空间内实施 Gram—Schmidt，因为线性组合仍留在同一个特征空间。

## 3. 完整例题
A=[[2,1],[1,2]] 的特征值为 3 和 1。对应向量分别为 (1,1)^T、(1,−1)^T。归一化后
Q=(1/√2)[[1,1],[1,−1]]，Λ=diag(3,1)。

验证 Q^TQ=I，Q^TAQ=Λ。对于 x=Qy，x^TAx=3y_1²+y_2²，直接显示该二次型正定。

## 4. 谱分解
A=Σ_i λ_i q_i q_i^T。每个 q_i q_i^T 是向特征方向的正交投影，分解把线性作用拆成各正交方向的伸缩。

若 A 正定，则可定义对称正定平方根 A^{1/2}=Q diag(√λ_i)Q^T。此处要求所有 λ_i>0；半正定时仍有半正定平方根，但不可逆。

## 5. Rayleigh 商
对非零 x，R_A(x)=x^TAx/(x^Tx)。实对称 A 满足 λ_min≤R_A(x)≤λ_max。将 x 展开到标准正交特征基即可证明，因为它是特征值的加权平均。

极值可以在对应特征向量方向达到。这一结论联系了特征值与二次型在单位球面的最值。

## 6. 检索提示与易错点
回答“为什么对称矩阵的不同特征向量正交”时，需要强调不同特征值；“所有特征向量都互相正交”不成立。

正交对角化需要归一化，不能只把未经归一化的独立特征向量放到 Q 中。那样可能得到可逆 P，却没有 Q^TQ=I。
