# 计算检查与证明方法

## 1. 维度检查
写出每个矩阵形状，再判断表达式是否有定义。A 为 m×n，A^TA 为 n×n，AA^T 为 m×m，二者即使秩相同也不能当成同一矩阵。

方程 Ax=b 中 x 长度为 n，b 长度为 m。投影 A(A^TA)^{-1}A^T 为 m×m，作用在右端项所在空间 R^m。

## 2. 代入验证
求解后将参数表达式代回全部原方程；求逆后检查乘积为单位阵；求特征向量后检查 Av=λv，且 v≠0；求正交矩阵后检查 Q^TQ=I。

可用 A^k 的 k=0、1 检查闭式是否合理。这些检查能发现错误，但检查几个参数值不能代替对所有值的证明。

## 3. 子空间与无关性的证明
证明子空间应给出非空与线性组合封闭；反驳可用不含零向量或不封闭的反例。

证明无关时设线性组合为零并证明各系数为零；证明相关时给出不全为零的系数。不要只用图像直觉判断高维无关性。

## 4. 等价命题与条件
“当且仅当”需要双向证明。“A 正定推出可逆”成立，但“可逆推出正定”错误，例如 −I。

“有 n 个互异特征值推出可对角化”是充分条件；对角化的必要充分条件是 n 个无关特征向量。回答时需区分充分、必要与等价。

## 5. 利用二次表达式
证明 A^TA 半正定只需计算 x^TA^TAx=||Ax||²≥0。若 A 满列秩，可进一步得到非零 x 时严格大于零，因此正定。

证明两个正定矩阵之和正定，可以写 x^T(A+B)x=x^TAx+x^TBx>0。注意正定矩阵的乘积一般不是对称矩阵，不能直接用同样方式判断为正定。

## 6. 与解集、核和像的联系
需要判定唯一性时，可考虑两个解之差。若 Ax1=Ax2，则 A(x1−x2)=0。核为零就得到相同；核非零且系统有解时就能产生不同解。

需要判定存在性时，考察右端项是否属于列空间。存在与唯一分别对应像与核，不要把这两个问题混同。

## 7. 引用与可信度
课程回答应能指出原文中的适用条件、论证或反例。知识点名称、相似关键词或图上的连边本身不是完整证明。

如果资料仅给出 SVD 的结论，用户要求某种具体迭代算法的实现，不能将结论改写成猜测的算法；应指出尚缺算法资料。
