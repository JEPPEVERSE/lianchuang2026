# 矩阵与矩阵运算

## 1. 定义、维度与记号
矩阵是按行列排列的数表。实矩阵 A∈R^{m×n} 有 m 行 n 列，元素记作 a_ij。行向量大小为 1×n，列向量大小为 m×1。只有行数等于列数的矩阵才叫方阵。矩阵的维度决定运算是否有定义，不能只看元素个数。

单位矩阵 I_n 的主对角元素为 1，其余为 0；零矩阵的所有元素为 0。对角矩阵只有主对角可能非零，上三角矩阵在主对角线下方为零。一个 n 阶对角矩阵可写为 diag(d_1,…,d_n)。

矩阵相等要求维度相同且对应元素相等。常见别名：“矩阵大小”“矩阵形状”“矩阵维度”在此都指 m×n；这与后文向量空间的维数不同。

## 2. 加法、数乘与乘法
同型矩阵才能相加，(A+B)_ij=a_ij+b_ij。数乘逐元素进行。矩阵乘法 AB 要求 A 的列数等于 B 的行数：m×k 乘 k×n 得到 m×n，元素 (AB)_ij=Σ_{t=1}^k a_it b_tj。

矩阵乘法具有结合律与分配律，但通常不满足交换律。AB 有定义并不保证 BA 有定义；即使二者都有定义且同型，也可能 AB≠BA。

若 A=[[1,2],[0,1]]，B=[[1,0],[3,1]]，则 AB=[[7,2],[3,1]]，BA=[[1,2],[3,7]]。

零乘积不推出某一因子为零。例如 A=[[1,0],[0,0]]，B=[[0,0],[0,1]] 均非零，但 AB=0。没有可逆性等额外条件时，也不能从 AB=AC 直接约掉 A。

## 3. 转置与对称
转置把行变为列：(A^T)_ij=a_ji。性质为 (A+B)^T=A^T+B^T，(cA)^T=cA^T，(AB)^T=B^T A^T。乘积转置时顺序反转。

实方阵满足 A^T=A 时称为对称矩阵。对任意实矩阵 A，A^T A 都是对称矩阵，但 A 本身未必对称。复矩阵中常使用共轭转置 A*；本资料除明确说明外均讨论实数域。

## 4. 矩阵表示线性映射
固定 A∈R^{m×n}，映射 T(x)=Ax 从 R^n 到 R^m，满足 T(αx+βy)=αT(x)+βT(y)。Ax 也是 A 的列向量按 x 的分量作线性组合。

若 A 的列为 a_1,…,a_n，则 Ax=x_1a_1+…+x_na_n。方程 Ax=b 因而等价于“b 是否能由 A 的列向量线性表示”。这是矩阵运算与方程组、列空间的连接。

## 5. 例题与检查
取 A=[[1,2,0],[0,1,1]]，x=(1,2,3)^T，则 Ax=(5,5)^T。A 是 2×3，输入有 3 个分量，输出有 2 个分量。

练习：若 A 为 2×3，B 为 3×4，则 AB 为 2×4，BA 无定义。若 C 为 2×2，则 CA 有定义，AC 无定义。
