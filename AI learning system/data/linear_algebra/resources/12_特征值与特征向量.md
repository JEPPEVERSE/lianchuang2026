# 特征值、特征向量与特征空间

## 1. 定义及非零条件
对方阵 A，若 Av=λv 且 v≠0，则 λ 为特征值，v 为其特征向量。也称 eigenvalue、eigenvector。特征向量非零是定义的一部分，但特征值可以为零。

几何上，A 作用在该方向上只进行数乘，λ 为负时方向反转。λ=0 表示该非零向量被映到零向量。

## 2. 求法
特征值满足 det(λI−A)=0，这称特征方程。确定 λ 后解 (A−λI)v=0，得到特征空间 E_λ=ker(A−λI)。

特征空间包含零向量；特征向量是该空间中所有非零向量。特征向量不唯一，非零倍数仍是相同特征值的特征向量。

## 3. 重数
特征值在特征多项式中的重数为代数重数；特征空间的维数为几何重数。对一个特征值，1≤几何重数≤代数重数。

不同特征值对应的特征向量线性无关。同一特征值对应的两个向量可能相关，也可能无关，需要看特征空间维数。

## 4. 例题
A=[[2,1],[0,3]] 的特征多项式为 (λ−2)(λ−3)。λ=2 时特征空间为 span((1,0)^T)；λ=3 时特征空间为 span((1,1)^T)。

B=[[1,1],[0,1]] 的唯一特征值为 1，代数重数为 2，但 E_1=span((1,0)^T)，几何重数只有 1。重复特征值不保证有足够多的独立特征向量。

## 5. 迹、行列式与可逆性
若在复数域按代数重数列出所有特征值 λ_1,…,λ_n，则 tr(A)=Σλ_i，det(A)=Πλ_i。迹是主对角线元素的和。

0 是特征值当且仅当 A 不可逆。若 Av=λv，则 A^k v=λ^k v。若 A 可逆，A^{-1}v=(1/λ)v。

## 6. 实数与复数边界
实矩阵可能没有实特征值。例如 [[0,−1],[1,0]] 的特征方程为 λ²+1=0，复特征值为 ±i。

因此“任何实方阵都存在实特征向量”是错误的。实对称矩阵具有实特征值是更强的特殊结论，见谱定理章节。
