# 逆矩阵、可逆性与 LU 分解

## 1. 逆矩阵的定义
对 n 阶方阵 A，若存在同阶 B 满足 AB=BA=I_n，则称 A 可逆，B=A^{-1}。可逆矩阵也称非奇异矩阵；不可逆矩阵称奇异矩阵。

逆矩阵唯一。若 B、C 都是逆，则 B=B(AC)=(BA)C=C。实数中的“除以 A”在矩阵运算里应明确表示左乘 A^{-1} 还是右乘 A^{-1}，两者一般不同。

## 2. 可逆性的等价条件
对实 n 阶方阵 A，下列条件等价：det(A)≠0；r(A)=n；列向量线性无关；Ax=0 只有零解；Ax=b 对任意 b∈R^n 都有唯一解；0 不是 A 的特征值。

这些条件中的“方阵”不可遗漏。矩形矩阵可能有左逆或右逆，但不属于本章的双侧逆定义。

## 3. 求逆方法
二阶矩阵 A=[[a,b],[c,d]] 在 ad−bc≠0 时有
A^{-1}=(1/(ad−bc))[[d,−b],[−c,a]]。

一般方阵可把 [A|I] 用初等行变换化为 [I|A^{-1}]。若左半部分不能化为单位阵，则 A 不可逆。伴随矩阵法使用 A^{-1}=adj(A)/det(A)，其中伴随矩阵是代数余子式矩阵的转置。

例如 A=[[1,2],[3,5]]，det(A)=−1，A^{-1}=[[-5,2],[3,-1]]。乘积 AA^{-1}=I 可直接验证。

## 4. 逆的运算顺序
若 A、B 均可逆，则 (AB)^{-1}=B^{-1}A^{-1}。此外 (A^T)^{-1}=(A^{-1})^T，(cA)^{-1}=c^{-1}A^{-1}，其中 c≠0。

通常 (A+B)^{-1} 不能拆成 A^{-1}+B^{-1}。若 AX=B，则 X=A^{-1}B；若 XA=B，则 X=BA^{-1}。不能交换乘法顺序。

## 5. LU 分解与消元
若消元无需换行且主元不为零，可把方阵写成 A=LU，其中 L 为单位下三角矩阵，U 为上三角矩阵。一般情况可能需要置换矩阵，写为 PA=LU。

例：A=[[2,1],[4,3]]，L=[[1,0],[2,1]]，U=[[2,1],[0,1]]。相乘可以恢复 A。解 Ax=b 时，先解 Ly=b，再解 Ux=y；多组右端项可以复用分解。

不是每个可逆矩阵都能在不换行情况下得到这种 LU，例如 [[0,1],[1,0]] 首个主元为零，需要换行。

## 6. 数值与概念边界
实际数值求解通常使用分解解方程，不显式计算逆矩阵。理论上的可逆不保证浮点运算稳定，接近奇异的矩阵可能对误差敏感。

本章不提供一般矩阵伪逆的完整定义；非方阵的最小二乘问题将在后文讨论。
