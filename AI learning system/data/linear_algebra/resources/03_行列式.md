# 行列式、余子式与可逆性

## 1. 行列式的对象
行列式 det(A) 或 |A| 是方阵对应的一个数，不是矩阵。非方阵没有通常意义下的行列式。二阶矩阵 [[a,b],[c,d]] 的行列式为 ad−bc。

行列式表达有向体积缩放。实 n 阶方阵的行列式为零，等价于其列向量线性相关；非零则表示线性映射没有把空间压缩到较低维。这一等价关系后续将与秩联系起来。

## 2. 余子式与展开
删除第 i 行第 j 列得到的子矩阵的行列式为余子式 M_ij；代数余子式为 C_ij=(−1)^{i+j}M_ij。

沿第 i 行展开：det(A)=Σ_j a_ij C_ij。沿列也可以展开。优先选择零元素多的行或列，通常能减少计算量。不要漏掉棋盘式正负号。

三阶矩阵可以使用专门的对角线法则，但该法则不能直接推广到四阶及更高阶。

## 3. 行操作对行列式的影响
交换两行使行列式变号；某行乘以 c，行列式乘以 c；一行加另一行的倍数，行列式不变。因此含零行、两行相同或两行成比例的方阵行列式为零。

上三角、下三角或对角矩阵的行列式等于主对角元素的乘积。对一般矩阵，可以记录行操作带来的系数与符号，再用三角形计算。

## 4. 常用公式及条件
同阶方阵有 det(AB)=det(A)det(B)，det(A^T)=det(A)，det(cA)=c^n det(A)。若 A 可逆，则 det(A^{-1})=1/det(A)。

通常 det(A+B)≠det(A)+det(B)。例如 A=B=I_2，左边为 4，右边为 2。数乘公式中的指数 n 不能遗漏。

分块上三角矩阵 [[A,B],[0,D]] 的行列式等于 det(A)det(D)，其中 A、D 必须为方形块。一般分块矩阵不能把标量二阶公式 ad−bc 不加条件地套在矩阵块上。

## 5. 例题
A=[[1,2,0],[0,3,1],[0,0,4]] 为上三角矩阵，det(A)=12。则 det(2A)=2^3×12=96。

B=[[1,2,3],[2,4,6],[0,1,1]] 第二行为第一行的两倍，所以 det(B)=0。

对 A(t)=[[t,1],[1,t]]，det(A(t))=t²−1。可逆当且仅当 t≠±1。行列式非零的条件不可简化为 t≠1。

## 6. 克拉默法则
若 n 个未知数的方程组 Ax=b 的系数矩阵满足 det(A)≠0，则唯一解 x_i=det(A_i)/det(A)，其中 A_i 把 A 的第 i 列替换为 b。

若 det(A)=0，不能使用该公式，且不能仅凭行列式为零断定无解；可能无解，也可能有无穷多解，需要比较系数矩阵与增广矩阵的秩。
